# Paynet Developers Lab — опубликованная GPT-версия

Отдельная публичная копия интерфейса Paynet Developers Lab, перенесённая с:
https://paynet-developers-lab-nov26.stoianovo.chatgpt.site/

## Состав

Полный интерфейс сайта: index.html, styles.css, core.js, data.js, content.js, app.js.
Также входят логотип paynet_business.svg, машиночитаемые материалы openapi.json и llms-full.txt.

## Публичный сайт

https://morfikozik.github.io/gpt-api-docs/

## Источник

ZIP-архив проекта предоставлен владельцем. Сверка выявила, что часть файлов опубликованного сайта отличается от ZIP. В репозиторий перенесены файлы именно текущей опубликованной версии по ссылке выше через изолированный GitHub Actions workflow.

## Безопасность

Портал может отправлять тестовые запросы в Paynet. Используйте только тестовые ключи; не вводите production-секреты в браузере.

## Изоляция

Изменения вносились исключительно в Morfikozik/gpt-api-docs. Репозиторий Claude не изменялся.
