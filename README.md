# Paynet Developer Docs — GPT Design Reference

**Отдельный визуальный прототип**, созданный для сравнения с работающим порталом Paynet.

- Боковая панель с группировкой операций и иконками
- Короткие объяснения платежей, возвратов, callback и сохранённых карт простым языком
- Три шага для каждого сценария
- Единый редактируемый JSON-блок с кнопкой **Test (simulation)**
- Мобильная навигация

**Важно:** это не рабочая интеграция Paynet. Test выполняет только локальный разбор JSON, не обращается к API и не требует ключей. Примеры JSON в прототипе не являются контрактом Paynet. Для технических деталей используйте [официальную документацию Paynet](https://morfikozik.github.io/paynet-docs/).

## Опубликовать через GitHub Pages

1. Откройте **Settings → Pages** в данном репозитории `Morfikozik/gpt-api-docs`.
2. В **Build and deployment → Source** выберите **Deploy from a branch**.
3. Выберите ветку **main**, каталог **/(root)** и нажмите **Save**.
4. После завершения публикации ссылка: https://morfikozik.github.io/gpt-api-docs/

Этот репозиторий независим от `Morfikozik/paynet-docs`. Изменения в другие репозитории не требуются.
